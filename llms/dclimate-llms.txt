# dClimate

> dClimate is a chain-agnostic, decentralized climate information ecosystem that makes it easy for businesses and builders to find, access, and utilize essential data about the planet. Access is SDK-first over content-addressed (IPFS/IPLD) storage: official Python and JavaScript clients resolve datasets from a STAC catalog and stream sharded Zarr stores. There is no public REST API, API key, or OAuth — public datasets are retrieved by content identifier (CID). Datasets span weather and climate reanalysis/forecast sources such as ECMWF ERA5 and AIFS, plus a data marketplace featuring sources like NASA and ESA.

## Products
- [Data Marketplace](https://alpha.marketplace.dclimate.net): Discover and access climate/weather datasets.
- [Aegis](https://aegis.dclimate.net): dClimate platform surface.
- [CYCLOPS](https://www.cyclops.ai/): Climate intelligence platform.

## SDKs
- [dclimate-client-py (PyPI)](https://pypi.org/project/dclimate-client-py/): Official Python client — `pip install dclimate-client-py`.
- [@dclimate/dclimate-client-js (npm)](https://www.npmjs.com/package/@dclimate/dclimate-client-js): Official JS/TS client — `npm install @dclimate/dclimate-client-js`.
- [py-hamt (PyPI)](https://pypi.org/project/py-hamt/): Content-addressed HAMT key-value mapping library.
- [jaxray](https://github.com/dClimate/jaxray): xarray-like labeled arrays for JavaScript.
